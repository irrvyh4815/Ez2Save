# Financial Calculations

所有核心財務計算都在 TypeScript deterministic utilities 中完成，不依賴 AI。

檔案：

- `src/lib/financialCalculations.ts`
- `src/lib/financialCalculations.test.ts`

## 金額單位

一般帳務金額統一使用帳本基準幣別的最小單位整數：

```text
100.00 基準幣別 = 10000 cents
```

顯示時才轉成千分位、不顯示不必要的小數。

## Dashboard

- 總資產 = 啟用帳戶餘額 + 未連結帳戶的存款本金 + 投資持倉現值
- 總負債 = 貸款剩餘本金 + 信用卡本期帳單 + 未出帳金額 + 未含於帳單的分期餘額
- 淨資產 = 總資產 - 總負債
- 本月結餘 = 本月收入 - 本月支出
- 緊急預備金月數 = 可動用存款 ÷ 最近三個月平均必要支出
- 負債比 = 總負債 ÷ 總資產

分母為 0 時回傳 0，避免 `NaN` 或 `Infinity`。

定存明細若已連結活儲或定存帳戶，總資產只採用帳戶餘額一次。信用卡分期若標示「已含帳單」，只作分期進度追蹤，不再額外占用一次額度。

## 貸款

支援：

- 本息平均攤還
- 本金平均攤還
- 固定金額還款
- 額外每月還款
- 一次性提前還款

輸出：

- 每月應繳
- 總利息
- 總還款金額
- 預計結清期數
- 節省利息
- 縮短期數
- 完整攤銷表

## 存款

支援：

- 單利
- 複利
- 每月追加
- 扣除率

輸出：

- 預估總利息
- 到期金額
- 實際年化報酬率
- 每月累積變化

## 信用卡與交易

- 信用卡消費列入支出，但不立即扣銀行帳戶。
- 信用卡繳款扣付款帳戶，但不再次列為一般支出。
- 帳戶轉帳不列為收入或支出。
- 帳單週期依結帳日判定本期/下期。
- 新增或刪除連動交易時，現金、卡片帳款、貸款本金、繳款紀錄與投資持倉會在同一資料庫交易中一起更新或還原。
- 投資買入與賣出屬資產轉換，不列入一般收入或支出。
## 外匯與加密資產估值

投資持倉採用手動價格與匯率，不在頁面載入時呼叫行情 API：

- 成本 = 數量 × 平均單價 × 報價幣別兌帳本幣別匯率
- 現值 = 數量 × 目前單價 × 報價幣別兌帳本幣別匯率
- 未實現損益 = 現值 − 成本
- 報酬率 = 未實現損益 ÷ 成本

最終帳本金額統一四捨五入到最小貨幣單位。分母為零時報酬率顯示為 0，避免 `NaN` 或 `Infinity`。
